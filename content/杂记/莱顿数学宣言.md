```ad-note
title:宣言背景
- **AI的发展正在重塑数学研究**：数学形式化、生成式人工智能、神经网络方法正在重塑数学研究的方式，是一个巨大的冲击。
- **数学学界不同的反应**：热情迎接、冷漠对待、悲观。
- **荣誉与责任并行**：数学工作者有权利选择和使用AI，并对研究结果负责，有责任维护数学学科的健康发展。
```

```ad-note
title:宣言适用人群
数学研究者、政策制定者、商业AI企业
```

```ad-note
title:数学研究价值观
- **证明是数学的核心**：数学证明提供了结论的准确性、并且能传授结论为何正确以及理解方式，证明支撑着数学学科的科学完整性。
- **结果归功于作者**：作者要对结果和证明负责。
- **结果透明且能验证**：不需要专有知识和设备来理解。
- **共同的评价标准**：深度、难度和意义。
- **自主性与专业判断**：研究方向和方法应由数学共同体自主塑造，而非外部技术公司主导。
```

```ad-note
title:AI对数学研究潜在的威胁
- **不可靠的论证**：AI可能生成看似合理但错误的证明，难以与正确论证区分，其中的困难在于概念的计算机编码和人类表示之间的转换。
- **引用系统的破坏**：AI模型使用大量数学文献但不恰当地引用或尊重版权。
- **影响奖励机制和评价体系**：AI能力可能成为评价标准，边缘化无资源或不愿使用特定AI工具的学者。有资源和能力使用AI的研究者，会更大程度地获得成果和奖励。
- **数学自主发展受威胁**：研究的品味会受到AI的主导，研究者们会优先选择更适合AI可行的问题，而非数学自身理论深度。只会导致AI级数公司介入数学研究，但从另一个观点来看，这样的研究模式或许会成为新范式，但需要合适的监管。
```

```ad-note
title:对数学家的建议
- **披露工具使用**：在论文中明确说明使用了哪些AI工具。
    
- **支持审稿工作**：提供清晰引用和形式化证明，帮助同行评审。
    
- **坚持开放科学原则**：数据、软件、方法应尽可能开放。
    
- **保留正确性责任**：AI不能替代人类对结果的最终责任。
    
- **确认作者的人类身份**：AI不能作为作者，责任和荣誉属于人。
    
- **主动归因**：即使AI未能引用，也要主动追溯和致谢源头。
    
- **参与公共讨论**：向公众解释AI辅助数学的实质。
    
- **了解技术进展**：保持对AI能力的理解，以便参与治理。
    
- **欢迎跨学科贡献者**：吸引外来人才，但也要求他们尊重数学价值观。
    
- **审慎选择工具**：优先使用非专有、能效高、小型化的系统。
    
- **评估伦理后果**：不参与用于战争、压迫、监控等领域的应用。
```

```ad-note
title:对数学组织和非营利性研究资助者的建议
- 建立AI在出版和审稿中的政策（如工具披露、归因规则）。
    
- 对AI辅助成果保持严格标准（如形式化验证、人工解释）。
    
- 保护作者权利：未经同意不得将论文用于训练AI。
    
- 坚持成果发表在同行评审渠道，新闻稿不能替代评审。
    
- 支持公共研究实验室（不受产业控制）。
    
- 提供法律和知识产权支持，帮助学者在与企业合作中保持平等地位。
    
- 将价值观对齐作为项目资助的考量因素。
```

```ad-note
title:给政策制定者的建议
- **保护作者权利**：加强版权和归因的法律保护。
    
- **不轻信炒作**：依赖专家意见而非企业宣传制定政策。
    
- **监管AI行业**：关注其在军事、监控、民主破坏等领域的影响。
    
- **投资公共计算基础设施**：提供大学和国家层面的公共AI资源。
```

```ad-note
title:对商业人工智能的建议
- 数学被用于展示AI能力，也被用作训练数据。
    
- 公司应遵守与本宣言一致的价值观，尊重学者的道德自主权。
    
- 数学界呼吁企业在合作中保障学者的良知自由，允许公开讨论企业政策。
```
